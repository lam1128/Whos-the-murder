## 一、货币制度

临川城通行三种货币：

- 铜币
- 银币
- 金币

统一换算为：

> **100铜币＝1银币**  
> **100银币＝1金币**  
> **1金币＝10000铜币**

### 使用习惯

- 铜币主要用于饭食、日用品、短途交通和普通服务。
- 银币主要用于房租、衣物、药材、职业工具、武器和较大金额交易。
- 金币用于精良装备、房产、大宗货物、稀有材料和大型危险行动。
- 普通居民日常生活中很少直接使用金币。
- 剧情中普通消费优先以铜币和银币表示，不把金币当作随手使用的零钱。

### 价格浮动

临川城正常时期的普通商品价格通常上下浮动一至三成。

主要影响因素包括：

- 季节与收成；
- 商队是否按时抵达；
- 河运和道路是否畅通；
- 妖兽活动是否增加；
- 药材和特殊材料的供应量。

药材、妖兽材料和灵力用品的价格波动通常大于普通粮食和日用品。

### 钱币面额与携带

临川城常见的钱币面额为：

- 铜币：1铜、5铜、10铜；
- 银币：1银、5银、10银；
- 金币：以1金币为主，实际流通很少。

几十银币以内的交易通常直接使用钱币。达到一金币或更高金额时，人们更倾向于使用钱庄存款或兑票，避免携带大量金银。

### 临川钱庄

临川城只有一家受官署认可的钱庄，正式名称为：

> **临川钱庄**

临川钱庄位于中心街区，主要提供：

- 存放铜币、银币与金币；
- 不同面额之间的兑换；
- 大额款项暂存；
- 开具和兑付兑票；
- 跨城汇兑与商队结算。

临川钱庄是独立经营机构，不属于官署日常部门。官署认可其账据与兑票，但不直接管理普通客户的日常存取。

### 兑票

兑票是临川钱庄在确认相应钱款已经存入后开出的支付凭证，不是普通纸币。

兑票主要用于：

- 一金币以上的大额交易；
- 房屋、商铺和大宗货物买卖；
- 精良装备与稀有材料定金；
- 跨城汇款；
- 大型委托报酬结算。

普通食铺和小摊通常不直接接受兑票。持票人需要到临川钱庄兑现，跨城兑付可能产生少量手续费。

### 承务所结算

临川承务所根据报酬规模提供不同结算方式：

- 普通委托可以直接领取现金；
- 较大金额可以记入接取者名下的暂存账户；
- 大额委托可以由承务所协助开具兑票。

委托公告中标明的报酬，是任务完成并通过验收后接取者可以获得的总金额。承务所的基础登记、托管与验收费用由委托方另行承担，不在结算时再次从接取者报酬中扣除。

玄甲林蜥任务的24银币属于普通现金结算范围。

### 储蓄与家庭资产

普通人的财富不一定全部以现钱存在。家庭资产可以包括：

- 铜币、银币和少量金币；
- 临川钱庄存款；
- 房屋、商铺和土地使用权；
- 粮食、布匹、牲畜与生产工具；
- 商铺库存；
- 职业装备、药材与妖兽材料。

职业修士的现金可能不多，但装备、药物和材料库存本身具有较高价值。王鸥这类灵药师尤其容易把收入重新投入药材与工具，因此不能只用手头现钱判断其生活状况。

## 十、居民收入

| 工作 | 收入 |
|---|---:|
| 普通短工 | 每日30—50铜币 |
| 搬运、码头或农忙重活 | 每日40—70铜币 |
| 熟练工匠 | 每日60—120铜币 |
| 学徒 | 每月4—10银币，可能包食宿 |
| 商铺伙计 | 每月8—15银币，部分包饭 |
| 普通账房或文书 | 每月12—22银币 |
| 官署基层职位 | 每月12—25银币 |
| 普通教师 | 每月15—30银币 |
| 有经验的医师或工匠 | 每月20—45银币 |
| 独立职业修士 | 收入波动很大 |

### 收入说明

- 普通短工每月工作二十四至二十六日，大约收入 **7—13银币**。
- 熟练工匠通常收入 **15—30银币/月**，拥有稳定客源或特殊技术者可能更高。
- 职业修士单次委托收入较高，但需要承担药物、装备、交通、伤势、等待任务和失败风险。
- 职业修士不可能稳定连续完成高风险任务。某个月可能赚到几十银币，也可能因为养伤或没有合适委托而几乎没有收入。

## 十二、职业装备价格体系

### 1. 适用范围

本节价格主要适用于需要长期承受灵力、直接影响职业能力的核心装备，例如：

- 长剑、匕首、长枪等主要武器；
- 专业符笔、导灵针具等核心职业器具；
- 需要专门材料、结构设计或个体适配的灵力装备。

普通衣物、行囊、绳索、灯具、基础伤药等探险与生活用品不机械套用核心装备品阶价格。

所有核心职业装备统一分为一阶至四阶，每阶再分为一品至五品：

> **同一阶中，一品最低，五品最高；五品之后进入下一阶一品。**

价格区间首尾相连。处在边界价格的装备，应根据材料、导灵结构、定制程度和实际功能判定品阶，不能只凭价格机械归类。

---

### 2. 一阶：学用与普通器具

一阶器具主要供学府学生、普通居民和非专业使用者使用。

共同特点：

- 使用结实的普通材料；
- 没有专门的灵力传导结构；
- 可以临时注入灵力，但损耗较大；
- 适合基础自保、学习和普通工作；
- 不具备固定灵纹或独立术式。

| 一阶二品 | 6—7银币 |
| 一阶三品 | 7—8银币 |

### 3. 二阶：职业器具

二阶器具针对具体职业优化，能够长期承担正式委托。

共同特点：

- 重心、韧性、尺寸和收纳方式更专业；
- 能够稳定承受较频繁的灵力注入；
- 随品级提高逐步增加导灵材料和个人适配；
- 可以进行尺寸、握柄、结构与受力方式调整；
- 整个二阶都没有完整固定灵纹；
- 核心作用是更好地发挥使用者自身能力。

| 品级 | 参考价格 | 大致定位 |
|---|---:|---|
| 二阶一品 | 10—25银币 | 入门职业器具 |
| 二阶二品 | 25—45银币 | 基础职业器具 |
| 二阶三品 | 45—75银币 | 标准职业器具 |
| 二阶四品 | 75—120银币 | 上等职业器具 |
| 二阶五品 | 120—200银币 | 精工半定制器具 |

#### 二阶一品

- 多为职业成品；
- 针对职业需要调整尺寸和结构；
- 能承受较频繁的基础注灵；
- 导灵材料较少；
- 常见于刚开始正式工作的职业者。

#### 二阶二品

- 材料更加耐用；
- 重心、握持和收纳结构更专业；
- 可以调整握柄、长度和配件；
- 灵力传导明显比一阶稳定。

#### 二阶三品

- 关键部位加入少量导灵材料；
- 能稳定承担长期任务；
- 可根据使用习惯进行一定调整；
- 适合已有一两年经验的职业者。

#### 二阶四品

- 使用质量更好的导灵材料；
- 灵力损耗进一步降低；
- 尺寸、重心和受力结构接近半定制；
- 适合成熟职业者长期使用。

#### 二阶五品

- 由专业工匠精工制作；
- 根据使用者身形和习惯进行半定制；
- 能承受长时间注灵与连续冲击；
- 属于普通职业器具的最高水平；
- 仍不具备完整导灵结构和固定灵纹。

何炅当前的核心长剑属于二阶五品，参考价值约130—150银币；除长剑外，他的其他主要装备最高不超过二阶四品。

三阶装备具有完整、稳定的导灵结构。随着品级提高，装备会逐渐加入个体适配和固定灵纹。

#### 三阶一品

- 具有完整连续的导灵结构；
- 灵力可以顺畅覆盖器物主要部位；
- 通常没有固定灵纹；
- 多数仍以成熟标准型号为基础。

#### 三阶二品

- 使用更优质的导灵金属或妖兽材料；
- 灵力损耗进一步降低；
- 可进行更多尺寸和结构调整；
- 长期使用的稳定性更高。

#### 三阶三品

- 开始根据使用者的灵力习惯进行个体适配；
- 导灵线路与发力方式相互配合；
- 可能具有一项非常基础的辅助灵纹；
- 更换使用者后效果可能下降。

#### 三阶四品

- 根据使用者的灵力性质和职业方式深度定制；

- 需要专业工匠长期制作；
- 维护和修复费用明显提高。

#### 三阶五品

- 使用三阶中较高品质的导灵材料；
- 导灵结构和固定灵纹高度稳定；

- 或具有两项效果有限、彼此辅助的灵纹；
- 属于正常市场能够接触到的高端装备。

## 十三、妖兽品级与基础委托报酬

妖兽分为：

- 低阶；
- 中阶；
- 高阶。

每一阶原则上再分为一品至五品。

> 同一阶中，一品最低，五品最高。

妖兽品级主要用于承务所和从业者估算危险、安排人员和制定报酬，并不是能够精确衡量每只个体的学术标准。

同一物种的个体可以在体型、年龄、耐力和战斗经验上存在差异，但通常不会因为单只个体稍强便临时改变整个物种的常用分类。

### 1. 低阶妖兽基础报酬

以下均为单只目标、种类已知、情报基本可靠、普通击杀或驱离条件下的整份委托总报酬。

| 品级 | 基础报酬 |
|---|---:|
| 低阶一品 | 5—7银币 |
| 低阶二品 | 7—10银币 |
| 低阶三品 | 10—14银币 |
| 低阶四品 | 14—20银币 |
| 低阶五品 | 20—25银币 |

说明：

- 低阶妖兽仍然能重伤甚至杀死普通人和经验不足的修士。
- 低阶一、二品适合毕业新人或普通城卫充分准备后处理。
- 低阶三品已经具有明显实战压力。
- 低阶四品通常适合有经验的小队。
- 低阶五品是低阶顶端，不能视为普通清理任务。

### 2. 中阶妖兽基础报酬

| 品级 | 基础报酬 |
|---|---:|
| 中阶一品 | 40—70银币 |
| 中阶二品 | 80—140银币 |
| 中阶三品 | 160—250银币 |
| 中阶四品 | 280—400银币 |
| 中阶五品 | 400—500银币 |

说明：

- 中阶妖兽通常活动在森林中层或其他明显危险区域。
- 越往后，能够接受任务的队伍越少，准备、药物、装备和伤亡风险越高，因此报酬增长明显加快。
- 临川城少数成熟队伍可以尝试处理中阶一品。
- 中阶二品已经需要当地最有经验的队伍充分准备。
- 中阶三品通常需要邀请外地成熟队伍。
- 中阶四、五品超出临川城的稳定处理能力。

### 3. 高阶妖兽与价格

高阶妖兽不属于临川承务所可以常规组织处理的目标。

#### 高阶一品

参考行动预算：

> **10000银币起，即100金币起。**

这一金额不是普通狩猎赏金，而是大型行动的最低规模，可能包含：

- 跨地区召集顶尖队伍；
- 前期调查；
- 特殊药物和装备；
- 区域封锁；
- 交通和运输；
- 人员伤亡补偿；
- 材料保存；
- 行动失败风险。

#### 高阶二品与三品

- 国家其他地区确认存在高阶一品、二品和三品妖兽。
- 高阶二品、三品没有全国统一公开价格。
- 相关任务由大型承务机构、地方或国家官署以及受邀顶尖队伍逐案评估。
- 实际行动成本会显著高于高阶一品。

#### 高阶四品与五品

- 目前只存在于古代典籍、灾害记录和不完整的历史记载中。
- 当前时代没有可靠、公开、可核实的常规猎杀记录。
- 不设市场价格，也不存在标准委托报酬。
- 若真实出现，首先考虑撤离、国家级应对和灾害控制，而不是材料交易。

## 十四、临川北部森林的高阶妖兽

临川北部森林内层确认生活着三只高阶一品妖兽。

它们属于同一家庭：

- 两只成年个体；
- 一只幼崽。

幼崽尚未拥有成年个体的完整战斗能力，但不能因此被视为低阶或中阶妖兽。两只成年个体会保护幼崽，因此这一家庭整体的实际危险远高于单独面对一只高阶一品。

临川城对它们采取以下原则：

- 记录大致活动区域；
- 警告猎人和修士避免深入领地；
- 不主动讨伐；
- 发现异常迁移时立即向上级报告；
- 若它们主动靠近城区，则转为地区性公共安全事件并向外求援。

临川城本身没有稳定处置高阶妖兽的能力。

普通人或私人机构如果为了材料主动猎取高阶妖兽，需要前往实力更强的地区，自行联系能够承担任务的顶尖队伍。

## 十五、妖兽委托的加价与减价因素

妖兽品级只决定基础危险，不单独决定最终报酬。

### 1. 常见加价因素

#### 搜寻困难

适用于：

- 没有明确位置；
- 活动范围较大；
- 需要长时间追踪；
- 可能需要野外过夜。

通常增加基础报酬的 **10%—30%**。

#### 材料完整要求

适用于：

- 必须取得完整甲壳；
- 不能火烧、腐蚀或大面积破坏；
- 必须达到指定尺寸和厚度；
- 战斗方式因材料要求受到限制。

通常增加基础报酬的 **10%—40%**。

#### 活捉要求

活捉通常比普通击杀困难得多，需要根据目标能力和运输条件单独定价，不机械套用固定百分比。

#### 环境危险

适用于：

- 深入森林中层；
- 洞穴、水下、悬崖等复杂地形；
- 周边存在其他妖兽；
- 撤离和运输困难。

通常增加基础报酬的 **20%—50%**。

#### 紧急与公共危险

适用于：

- 有人受困；
- 妖兽正在接近居民区；
- 存在明确时间限制；
- 已造成连续伤亡。

通常增加基础报酬的 **30%—100%**，也可能直接转为官署与承务所共同处理的公共安全事件。

### 2. 常见减价因素

- 已经确认准确位置；
- 官署或城卫负责封锁和运输；
- 只需驱离，不要求追踪击杀；
- 妖兽已经明显虚弱或受困；
- 剩余材料全部归接取者；
- 委托期限宽裕，没有紧急压力。

如果妖兽尸体及其材料归接取者，现金报酬可能位于基础区间下段；如果委托方要求带回全部高价值材料，现金报酬应明显提高。

## 十六、玄甲林蜥委托的正式结算

### 1. 妖兽与委托等级

- 妖兽：玄甲林蜥；
- 分类：低阶五品；
- 普通基础报酬：20银币。

### 2. 额外要求

委托方要求取得成年玄甲林蜥的主背甲，并且：

- 达到指定长宽；
- 达到指定中央厚度；
- 不得大面积断裂；
- 不得火烧；
- 不得腐蚀。

材料完整要求增加基础报酬的 **20%**。

计算：

> 20银币 × 120%＝24银币

因此，第三章玄甲林蜥委托的正式现金报酬为：

> **24银币**

### 3. 材料归属

- 委托方只取得合格主背甲；
- 主背甲验收后不再属于三人；
- 其余合理携带回来的玄甲、爪、牙、筋腱及药用材料归三人所有；
- 剩余材料可以出售、保留或用于装备加工。

### 4. 当前采用的成本与收入估算

| 项目 | 金额 |
|---|---:|
| 委托现金报酬 | 24银币 |
| 出售部分剩余材料 | 约6银币 |
| 补回药物、干粮和装备损耗 | −6银币 |
| 最终可分现金 | 24银币 |

最终三人平分：

> **每人获得8银币。**

另外还可以保留少量玄甲林蜥材料，用于制作小型护具、加固药匣或抵扣加工材料费。

这笔收入足以让三人高兴，也足以支持维修、补充耗材或为二阶低品装备积攒资金，但不足以让任何人仅靠这一次任务购买三阶精良导灵装备。

## 十七、金额的直观意义

- **1—5铜币**：小吃、茶水、普通短程服务。
- **10—30铜币**：一顿饭、普通问诊或短途搭车。
- **1银币**：一个成年人几天的基本饮食，或一件普通家用品。
- **5银币**：普通劳动者约半个月收入，也是低阶一品妖兽委托的最低总报酬。
- **10银币**：较大的个人消费，可以支付简单房租或购买一阶高品器具。
- **20—75银币**：职业者需要认真考虑的二阶低至中品装备投资。
- **75—200银币**：二阶高品核心武器或半定制器具，需要较长时间积累。
- **200—1000银币**：三阶精良导灵装备，需要长期积蓄、定制与持续维护。
- **1000银币以上**：四阶高阶定制灵器，远超普通年轻职业者的日常购买能力。
- **100银币＝1金币**：普通居民很难轻易拿出的重大金额。
- **10000银币＝100金币**：高阶一品妖兽行动的最低规模，已经脱离普通个人生活与普通委托范畴。

## 十八、剧情使用原则

1. 普通饭食和日常用品不需要每次精确结算，但必须保持价格尺度一致。
2. 一顿普通饭不会让职业修士感到负担，长期在酒楼吃饭则会明显增加开支。
3. 普通居民购买一套新衣、支付较高医药费或购买一阶器具时需要认真考虑。
4. 十银币以上属于普通人的重要消费，二阶核心装备属于职业性投资。
5. 二阶高品核心武器需要较长时间积累；三阶装备通常需要长期存钱、定制和维护。
6. 金币不能写成普通年轻人随手使用的零钱。
7. 妖兽委托标注的是整份任务总报酬，不是每名成员各得同样金额。
8. 委托完成后应先计算共同消耗，再分配净收益。
9. 灵药师自带的药物、针具和处理用品也有真实成本，不能默认免费。
10. 妖兽材料的价值取决于完整程度、保存状态、市场需求和是否便于运输。
11. 完成一次低阶任务可以支持维修或小幅升级装备，不能直接让全队获得高级灵器。
12. 高阶妖兽不属于临川承务所的日常委托范围。

## 十九、旧设定覆盖说明

本文件正式采用以下新规则：

- `100铜币＝1银币`；
- `100银币＝1金币`；
- 妖兽分类使用“品”，不再使用“档”；
- 玄甲林蜥统一称为“低阶五品”；
- 玄甲林蜥委托基础报酬为20银币；
- 因完整主背甲要求加价20%，最终委托报酬为24银币；
- 临川北部森林内层生活着两只成年高阶一品妖兽与一只幼崽；
- 高阶一品行动预算从10000银币起；
- 高阶二品、三品逐案评估，不设统一公开价格；
- 高阶四品、五品仅见于书中记载，不设价格；
- 临川城只有一家受官署认可的钱庄，名为“临川钱庄”；
- 一金币以上的大额交易通常使用钱庄存款或兑票；
- 承务所公告所列报酬为接取者通过验收后可获得的总金额。
- 核心职业装备统一分为一阶至四阶，每阶再分一品至五品；同阶一品最低、五品最高。
- 核心职业武器与专业灵力器具采用新版连续价格区间；基础探险衣物、行囊、绳索、灯具和基础伤药价格保持不变。
- 何炅当前核心长剑为二阶五品，其他主要装备最高不超过二阶四品。

旧文件中与上述货币换算、价格、品级名称、玄甲林蜥报酬或金融结算规则冲突的内容，均以本文件为准，后续应在更新 Project Knowledge、Scenario 和章节总结时统一同步。
